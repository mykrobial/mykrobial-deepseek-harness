# Mykrobial scientific bundle

This static DeepSeek bundle adds the host-plane `ctx.scientificRetrodiction` provider and makes `mykrobial-retrodict` the Web profile's default agent preset.

The row stays on the host plane because OmniGent and replay carriers must resolve one process-level service while all mutable state remains keyed by DeepSeek Session. The model-facing `retrodict` tool is mounted inside the agent preset and therefore remains agent-scoped.
