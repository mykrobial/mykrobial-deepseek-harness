# Mykrobial integration projections

This package contains pure, source-safe boundary transforms only:

- DeepSeek scientific event to a blocked, metadata-only Mykrobial Trace V2.3 append intent;
- OmniRoute request and exact requested/routed/served/provider receipt projection;
- DeepSeek event stream to a read-only MindWalk-style temporal timeline;
- strict Semantica-derived bitemporal assertions and Allen interval relations;
- hash-bound OmniGent scientific view state.

It does not contact any endpoint, append Trace, execute a model, start Semantica or MindWalk, mutate OmniGent, or deploy a service.
