# Mykrobial domain learning-signal seam

This package exposes the shared cross-generation event and intervention shapes only. It covers the accepted domain registry dimensions and forces future-domain signals to no-op. Every intervention remains `proposed_unapplied`; training, promotion, application, and deployment authority are fixed false.

The RSI lane owns the optimizer, evaluator firewall, experiment registry, Pareto promotion, rollback decision, causal value readback, and training authority. This package does not duplicate or invoke them.
