# Mykrobial dynamic loadout selector

This pure package turns a task diagnosis, a frozen policy, and an organ catalog into the cheapest dependency-closed organ plan that covers the requested capabilities. Only source-verified, lifecycle-tested, activation-admitted organs are eligible. Simulator and novelty capability sets are added only after the corresponding RetroDICT posture transition.

The result is always an unactivated plan. It does not mount components, execute tools or models, grant authority, mutate the catalog, or deploy a profile.
