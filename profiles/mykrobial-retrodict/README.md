# Mykrobial RetroDICT profile candidate

Bundle order is official DeepSeek base, official Web application, then the independently owned Mykrobial scientific layer. This preserves upstream core files and makes all Mykrobial behavior additive and removable.

This directory is an in-repository source template. Its dependency is an explicit relative `link:` to the sibling bundle so a later admitted checkout fixture cannot silently resolve a registry package. A deployment packet must materialize an exact profile path separately. It has not been copied to `DSH_HOME`, installed, composed, booted, or served.
